# Homebrew tap для Orbit

[Orbit](https://github.com/inkstatim/orbit-releases) — бесплатный анализатор диска для macOS.

```bash
brew install inkstatim/orbit/orbit
```

Обновление: `brew upgrade orbit` (Orbit и сам предлагает обновления). Удаление: `brew uninstall orbit`.
